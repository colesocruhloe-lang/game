# Urban Clash — Vice District

Браузерная 3D-игра в открытом мире в стиле неонового курортного города. Чистый WebGL, без библиотек и сборки — работает прямо на GitHub Pages.

## Что есть в игре
- Остров-город: даунтаун с небоскрёбами, пастельные ар-деко отели на Ocean Drive, пляж с пальмами, зонтиками, вышками спасателей и пирсом, парки с фонтанами, парковки.
- Смена дня и ночи: закат, неоновая ночь со светящимися окнами и фонарями, рассвет.
- Живой трафик по полосам с поворотами на перекрёстках, пешеходы на тротуарах и пляже.
- Угон любой машины (5 моделей), аркадная физика с заносом и ручником, повреждения, дым, взрывы.
- Стрельба с прицеливанием, перезарядка, трассеры.
- Розыск до 5 звёзд, погоня полиции, арест или больница.
- Цепочка заданий и случайные доставки на время.
- Мини-карта, HUD, радио с синтвейвом, звуки двигателя, сирены и выстрелов.
- Камера от 3-го и 1-го лица, сенсорное управление на телефоне.

## Управление
WASD — движение · Shift — бег · Space — прыжок / ручник · Мышь — обзор · ЛКМ — огонь · ПКМ — прицел · R — перезарядка · E/F — сесть/выйти · V — камера · Q — радио · M — звук · H — подсказка · Esc — пауза

## Файлы
`index.html`, `style.css`, `main.js`, `README.md` — положите в корень репозитория, GitHub Pages откроет `index.html`.
