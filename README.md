# Urban Clash — Vice District

Готовая браузерная 3D-игра на Three.js, рассчитанная на GitHub Pages.

## Запуск
Откройте `index.html` через GitHub Pages или любой статический веб-сервер. Интернет нужен для загрузки Three.js с jsDelivr.

## Управление
WASD — движение
SHIFT — бег
SPACE — прыжок
CTRL — присесть
E — сесть в автомобиль
F — выйти
ЛКМ — стрельба
TAB — таблица игроков

Проект использует оригинальные процедурно созданные модели города, транспорта и персонажей и не содержит проприетарных ассетов GTA.
