# Urban Clash — Vice District — Market Build

Полностью автономная браузерная игра без внешних CDN и библиотек.
Это оригинальная игра, а не копия GTA 6 и не содержит её проприетарных моделей/ассетов.

## Запуск
Загрузить `index.html` на GitHub Pages.

## Управление
WASD — движение
SHIFT — бег
SPACE — прыжок
E/F — автомобиль
ЛКМ — стрельба
TAB — таблица игроков

На мобильном экране доступны сенсорные кнопки.
